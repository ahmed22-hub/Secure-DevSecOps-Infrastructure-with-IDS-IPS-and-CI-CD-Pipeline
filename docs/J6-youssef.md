# 📅 Jour 6 — Développement de l'application

## 🎯 Objectif
Créer une application web simple mais fonctionnelle.

## 🧱 Réalisation
Application Flask avec 3 routes:
- / → accueil
- /health → status
- /login → simulation login

## ⚙️ Commandes
pip install -r requirements.txt
python app.py

## 🧪 Test
http://localhost:5000
http://localhost:5000/health

## 📌 Résultat
Application prête pour Docker
