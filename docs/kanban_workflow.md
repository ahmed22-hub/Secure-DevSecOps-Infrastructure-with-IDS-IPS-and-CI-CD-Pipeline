# Kanban Workflow and Definition of Done

## Purpose
This document explains how the team tracks daily work, proofs, and progress during the project.

The objective is to avoid chaos by using a simple and clear work method that both team members can follow.

## Tool Used
The team uses Notion as the Kanban tool to organize tasks and follow progress.

## Kanban Columns
The Kanban board contains the following columns:

- **Backlog**: tasks planned but not started yet
- **En cours**: tasks currently in progress
- **A tester**: tasks technically finished but still needing verification
- **Termine**: tasks completed, verified, and documented

## Daily Ritual
Each working day follows the same routine:

1. Read the objective of the day
2. Open the ticket or task of the day
3. Perform the main work
4. Run a simple verification or test
5. Take at least one useful screenshot
6. Update the progress note
7. Create a clean Git commit
8. Do a short sync point with Ahmed

## Definition of Done
A task is considered done only if all of the following conditions are met:

- the work is completed
- a test or verification has been done
- a proof has been saved
- the progress note has been updated
- the code or documentation has been pushed to the repository
