# Nginx

## Purpose
This directory contains the configuration of the Nginx reverse proxy used to expose and route traffic to the application.

## Expected Content
This folder may include:
- Nginx configuration files
- reverse proxy rules
- upstream definitions
- security header configuration
- basic hardening settings
- future WAF-related integration points

## Operational Role
Nginx will act as the entry point for client requests and will forward traffic to the backend application in a controlled and structured manner.

## Status
Prepared for reverse proxy configuration.
